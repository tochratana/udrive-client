# Google Sans for Khmer

UDrive bundles the unmodified Google Sans variable font and registers it as
Qt's application fallback for the Khmer script. English and Chinese retain
their existing fonts. Loading is local and does not install a system font or
contact Google at runtime.

- Project: https://github.com/googlefonts/googlesans
- Download: https://github.com/google/fonts/blob/main/ofl/googlesans/GoogleSans%5BGRAD,opsz,wght%5D.ttf
- Downloaded: 2026-10-16
- SHA-256: `d0a87d835a944b8b40d0e82a5651bb59ab97b936a2aeed5946eb57e7b2a3a90a`
- Original filename: `GoogleSans[GRAD,opsz,wght].ttf`
- License: SIL Open Font License 1.1, included in `GoogleSans-OFL.txt` and embedded
  alongside the font in the client resources.

The font's supported subsets, including Khmer, are listed in Google's
[metadata](https://github.com/google/fonts/blob/main/ofl/googlesans/METADATA.pb).
